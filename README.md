# Financial Fraud Detection System

## Overview

This project is a Real-Time Financial Fraud Detection System built using Machine Learning, Apache Kafka, MySQL, FastAPI, Streamlit, and Power BI.

## Features

* Real-time transaction streaming using Kafka
* Fraud detection using Machine Learning
* Customer behavior analysis
* Risk score calculation
* Fraud alert generation
* Email notifications
* MySQL database storage
* FastAPI REST APIs
* Streamlit dashboard
* Power BI analytics dashboard

## Technologies Used

* Python
* Scikit-Learn
* Apache Kafka
* MySQL
* FastAPI
* Streamlit
* Power BI
* Pandas
* Joblib

## Project Architecture

Dataset → Kafka Producer → Kafka Topic → Kafka Consumer → ML Model → Risk Scoring → MySQL → FastAPI / Streamlit / Power BI
